# Live-Wallpaper_Roulette

This simple bash script is the same as those two repositories that I posted in github. 
It uses mpvpaper for LIVE wallpaper that changes every 15 minutes by default.
It's also easier to add a live wallpaper.

## Requirements 

* Hyprland (or other linux distro)
* Bash
* mpvpaper (You can download it "yay -S mpvpaper)

## Customization

1. You should find the path of the bash script and that speficif live wallpaper directory.
2. There's a specific directory to put the live wallpaper, cp(copy) the .mp4(or other video formats) to that path.
3. Edit the bash script using nano or mousepad.
4. Just add the "$WALLDIR/yourlivewallpaper.mp4" at the end or whenever you like inside the wallpapers=()
